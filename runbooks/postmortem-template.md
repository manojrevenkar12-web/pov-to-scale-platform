# Postmortem: <title>

Blameless. Written within two working days of a paging incident.

1. Summary: what happened, who was affected (engagement, client), for how long.
2. Timeline (UTC): detection, first response, mitigation, resolution.
3. Detection: which alert fired, and how long after the start.
4. Root cause and contributing factors.
5. What went well, what did not.
6. Actions, each with an owner and a date; each one either prevents the cause or detects it sooner.
